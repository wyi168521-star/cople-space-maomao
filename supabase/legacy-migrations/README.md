# 原迁移归档

此目录保留整理前的 23 个迁移文件，供已有部署和兼容性回归测试使用，不由本地 Supabase 自动执行。

`messages`、`couple_letters` 仍在使用。原迁移失败的原因是它们的建表脚本位于迁移目录外，并非这些表已废弃。

本地全新初始化现在只执行：

1. `20261026000000_baseline.sql`：依次合入原有建表脚本、遗漏的基础功能脚本和历史升级。
2. `20261027162443_align_schema.sql`：最终列、约束、权限、RLS 与私有 Storage 对齐。

后续增量迁移继续放在活动目录，例如 `20261029132447_pairing_rpc.sql`；基础生成脚本会保留这些新迁移。

来源顺序及原文件 SHA-256 保存在 `baseline-sources.json`。修改来源后运行 `node supabase/scripts/rebuild-baseline.mjs` 可重新生成基础迁移。

合并后的版本用于本地重新初始化；已有部署保留原迁移历史，不把本地合并历史直接作为增量更新推送。
