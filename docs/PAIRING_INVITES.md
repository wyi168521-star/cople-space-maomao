# 专属邀请链接

创建空间后，配对页会直接展示完整邀请链接和“复制邀请链接”按钮。
以后也可从首页的“邀请另一半”进入 `/pairing` 再次复制。
链接使用当前站点域名，格式为 `/pairing?invite=<couple_id>`。

另一半点开后：

1. 未登录时先进入带有邀请参数的登录页，可选择登录或注册。
2. 登录或注册完成后回到配对页，自动切换到“加入空间”并填好编号。
3. 点击“确认加入这个小家”才调用现有 `join_couple` RPC；成功后进入首页。

无需额外数据库迁移、公开查询空间信息或新环境变量。
加入操作继续由现有 RPC 检查空间存在性、两人上限和用户是否已经配对。
已配对账号打开其他邀请时显示说明，不会自动换绑。
旧的手动输入 UUID 方式继续可用。复制权限不可用时，会选中链接供手动复制。
重复的 invite 参数、无效 UUID 和外部网址都不会作为加入目标。

如果以后重新开启邮箱验证，注册与重发邮件也会携带邀请回跳地址；
需在 Supabase Authentication → URL Configuration 中允许正式站点的
`/pairing` 邀请回跳地址。当前关闭邮箱确认的注册流程可直接保留邀请并继续配对。

邀请链接复用现有 UUID 加入规则，没有另外引入有效期或一次性令牌机制。
